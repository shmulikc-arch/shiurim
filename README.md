# מעיינות – אפליקציית שיעורי חסידות (שם זמני)

אפליקציית ווב (PWA) להאזנה לשיעורי הרב יואב אקריש: חיפוש, סינון לפי חומש, פרשת השבוע, המשך מאיפה שעצרת, שינוי מהירות, דילוג 30 שניות, טיימר כיבוי, מעבר אוטומטי לשיעור הבא, שמורים, שליטה ממסך הנעילה ומכפתורי ההגה (בלוטות'), הגדלת טקסט והתקנה למסך הבית.

## הקבצים
| קובץ | מה הוא |
|---|---|
| `index.html` | כל האפליקציה (עיצוב + קוד) |
| `catalog.json` | קטלוג לדוגמה: 8 תיקיות, 48 שיעורים. משמש רק עד שמחברים את הסנכרון |
| `manifest.webmanifest`, `sw.js`, `icons/` | מה שהופך את האתר לאפליקציה שאפשר להתקין |
| `apps-script/Code.gs` | סקריפט שבונה את הקטלוג המלא מהדרייב ומתעדכן כל שעה |

## שלב 1 – העלאה ל-GitHub Pages
1. יוצרים ריפו חדש (למשל `shiurim`) ומעלים אליו את כל הקבצים, בלי תיקיית `apps-script`.
2. Settings → Pages → Branch: `main` / root → Save.
3. אחרי דקה-שתיים האתר עולה בכתובת `https://<user>.github.io/shiurim/`.
4. **בדיקה חשובה:** פותחים בטלפון ומנגנים שיעור. ככה מוודאים שהניגון מהדרייב עובד.

## שלב 2 – חיבור הקטלוג המלא (Apps Script)
1. נכנסים ל-script.google.com → New project, ומדביקים את התוכן של `Code.gs`.
2. מריצים את `installHourlyTrigger` ומאשרים הרשאות. הסקריפט בונה את הקטלוג ויוצר רענון אוטומטי כל שעה.
3. Deploy → New deployment → Web app → Execute as: **Me**, Who has access: **Anyone** → Deploy.
4. מעתיקים את כתובת ה-Web App ומדביקים אותה ב-`index.html` בשורה:
   `CATALOG_URL: ''` ← בין הגרשיים.
5. מעלים מחדש את `index.html`. מעכשיו כל שיעור שיועלה לדרייב יופיע באתר תוך שעה, בלי שום פעולה ידנית.

רב או סדרה נוספים: מוסיפים שורה ל-`SOURCES` בראש הסקריפט.

## שלב 3 (בהמשך) – מעבר ל-Cloudflare R2
כשמחליטים לעבור, כל שיעור בקטלוג יקבל שדה `url` עם הכתובת ב-R2, והאפליקציה תנגן ממנה אוטומטית. לא צריך לשנות שום דבר אחר בקוד. בשלב הזה אפשר להוסיף גם הורדה להאזנה בלי קליטה.
