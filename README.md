# מעיינות – שיעורי חסידות (שם זמני)

אפליקציית ווב (PWA) להאזנה לשיעורי חסידות של כמה רבנים, לפי פרשות השבוע והמועדים.

## איך זה עובד
- **השיעורים נשארים בגוגל דרייב.** האתר מנגן אותם דרך Google Drive API עם מפתח שנעול לאתר הזה בלבד.
- **רשימת השיעורים (`library.json`) מתעדכנת אוטומטית כל שעה**, על ידי GitHub Action (`.github/workflows/catalog.yml`) שמריץ את `scripts/build_catalog.py`.
- שיעור חדש שעולה לאחת התיקיות בדרייב מופיע באתר תוך שעה, בלי שום פעולה ידנית.

## הוספת רב או תיקייה
עורכים את `sources.json`: שם, תמונה (קובץ jpg ריבועי בתיקייה הראשית) ומזהה תיקיית הדרייב. ה-Action ירוץ מיד אחרי השמירה.

## קבצים עיקריים
| קובץ | תפקיד |
|---|---|
| `index.html` | כל האפליקציה |
| `library.json` | רשימת השיעורים, נוצרת אוטומטית. לא לערוך ידנית |
| `sources.json` | רשימת הרבנים והתיקיות |
| `r-*.jpg` | תמונות הרבנים |
| `sw.js`, `manifest.webmanifest`, `*.png` | התקנה כאפליקציה ועבודה בלי קליטה |
| `*.woff2` | גופנים |
